# Smart City Route Optimization System (DAA Capstone)

Run:
    pip install -r requirements.txt
    python app.py
Then open http://127.0.0.1:5000

Files:
- algorithms.py  : Graph class, Dijkstra, Bellman-Ford, timing, random graph generator
- app.py         : Flask server (page + 2 small API routes)
- templates/     : index.html
- static/        : style.css
